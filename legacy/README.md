# Renamed to costproof

This package is now called **costproof**:

```bash
pip install costproof
```

`import costproof` and the `costproof` command replace `mixed_model_cost` and `mmco`. The old names keep working until version 1.0, with a deprecation note.

Installing `ai-mixed-model-cost-optimization` still works: it simply installs `costproof`.

→ https://pypi.org/project/costproof/ · https://github.com/AndyJakob78/costproof
