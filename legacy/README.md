# Renamed to valueproof

This package is now called **valueproof**:

```bash
pip install valueproof
```

`import valueproof` and the `valueproof` command replace `mixed_model_cost` and `mmco`. The old names keep working until version 1.0, with a deprecation note.

Installing `ai-mixed-model-cost-optimization` still works: it simply installs `valueproof`.

→ https://pypi.org/project/valueproof/ · https://github.com/AndyJakob78/valueproof
